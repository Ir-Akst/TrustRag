\begin{abstract}
Retrieval-Augmented Generation (RAG) empowers large language models (LLMs) with external knowledge, but introduces two severe, interconnected vulnerabilities: knowledge base poisoning and generation hallucinations. Existing defenses treat these failure modes independently: pre-retrieval filtering addresses corpus poisoning but is blind to generative hallucinations, while post-generation natural language inference (NLI) detects ungrounded claims but is easily deceived when retrieved premises are poisoned. In this paper, we introduce \textbf{TrustRAG}, a tri-layer defense architecture integrating: (1) \textbf{G1}, a query guardrail for prompt injection and directive filtering; (2) \textbf{G2}, a multi-signal pre-generation consensus gate incorporating source tiering, lexical anomaly detection, and consensus deviation filtering with a strict removal cap ($C_r = 0.50$); and (3) \textbf{G3}, an evidence verifier powered by a CPU-optimized, premise-normalized DeBERTa-v3-small NLI classifier. Evaluated on canonical benchmarks ($N=875$ attacks, $N=1,000$ clean controls), TrustRAG achieves a \textbf{100.00\% Attack Defense Rate (ADR)} with \textbf{0.00\% Clean False Positive Rate (FPR)} at a median CPU latency of \textbf{55.84 ms}. On commercial LLM generation benchmarks, TrustRAG defends \textbf{66.00\%} of hallucinations on RAGTruth (ACL 2024) and \textbf{89.00\%} on HaluEval (EMNLP 2023). Adversarial red-teaming across 15 attack vectors ($N=460$) confirms complete defense against static injections while delineating systemic boundaries under Sybil consensus and subtle paraphrased contradictions.
\end{abstract}

\section{Introduction}
Retrieval-Augmented Generation (RAG) mitigates parametric memory obsolescence and hallucination by retrieving relevant context from external knowledge stores. However, the external retrieval channel exposes RAG systems to adversarial corpus poisoning, wherein malicious actors inject corrupted or backdoor passages into indexed documents. Furthermore, generative models frequently introduce ungrounded extrinsic assertions.

Recent defenses attempt to mitigate these threats in isolation. Pre-generation filters such as FilterRAG \cite{filterrag2025} employ frequency-density clustering to eliminate poisoned passages, but possess no mechanism to verify generator hallucinations. Conversely, post-generation verifiers like HalluGuard evaluate sentence entailment, but validate false assertions if the retrieved premise was successfully poisoned.

To bridge this divide, TrustRAG implements a unified pipeline:
\begin{equation}
\mathcal{S}(q, \mathcal{C}, y) = \mathcal{G}_1(q) \land \mathcal{G}_2(\text{TopK}(q, \mathcal{C})) \land \mathcal{G}_3(\mathcal{P}_{\text{admit}}, y)
\end{equation}

\section{System Architecture}
\subsection{Layer G1: Input Guardrail}
Layer G1 inspects the raw query $q$ prior to retrieval. It combines lexical pattern filters with intent classification to intercept direct prompt injections and roleplay jailbreaks within $3.5\text{ ms}$.

\subsection{Layer G2: Multi-Signal Detector (MSD)}
Layer G2 assesses the candidate retrieval pool $\mathcal{P} = \{p_1, \dots, p_K\}$ across five orthogonal signals:
\begin{enumerate}
    \item Domain reputation tiering ($S_1$)
    \item Lexical and token entropy anomalies ($S_2$)
    \item Metadata structural integrity ($S_3$)
    \item Script and language alignment ($S_4$)
    \item Consensus embedding deviation ($S_5$):
    \begin{equation}
    S_5(p_i) = 1 - \cos\left(\mathbf{e}_i, \frac{1}{|\mathcal{P} \setminus \{p_i\}|}\sum_{j \ne i} \mathbf{e}_j\right)
    \end{equation}
\end{enumerate}
G2 caps total passage pruning at $C_r = 0.50$ to avoid context starvation.

\subsection{Layer G3: Premise-Normalized Neural NLI}
Layer G3 verifies factual entailment between admitted context $P$ and the generated response $H$ using fine-tuned DeBERTa-v3-small (86M parameters). To eliminate false contradictions triggered by bracketed citation markers, G3 applies regex premise normalization:
\begin{equation}
\tilde{P} = \text{regex\_replace}(P, \text{r'\[(?:Doc-)?\d+\]'}, \text{''})
\end{equation}
Under multi-threaded CPU execution (2 threads), median latency is reduced to $55.84\text{ ms}$.

On HaluEval, TrustRAG exhibits a $98.00\%$ clean FPR due to the \textit{Propositional Dilemma}: concise entity answers lack declarative sentential structure, leading standard NLI models to assign mass to \texttt{NEUTRAL}, triggering conservative safety quarantine.

\subsection{NLI Validation Diagnostics}
Evaluation on $N=2,662$ held-out validation samples reveals:
\begin{itemize}
    \item Overall Accuracy: $70.40\%$, Macro F1: $55.04\%$
    \item Entailment F1: $82.30\%$ (Precision: $74.80\%$, Recall: $91.46\%$)
    \item Contradiction F1: $36.22\%$ (Precision: $63.83\%$, Recall: $25.28\%$)
\end{itemize}
The low contradiction recall stems from severe class imbalance during supervised fine-tuning ($62.0\%$ Entailment vs $13.1\%$ Contradiction).

\section{Security Boundaries \& Adversarial Red-Teaming}
Red-teaming across 15 categories ($N=460$) reveals two structural boundaries:
\begin{enumerate}
    \item \textbf{Sybil Consensus Attacks:} Adversaries injecting $\ge 3$ agreeing passages overwhelm G2's removal cap ($C_r = 0.50$), forcing admission of poisoned context.
    \item \textbf{Paraphrased Contradiction:} High-fluency semantic paraphrasing bypasses lexical filters and exploits DeBERTa's $25.28\%$ contradiction recall.
\end{enumerate}

\section{Conclusion}
TrustRAG proves that robust RAG defense requires multi-gate defense-in-depth. By coupling query filtering, consensus gating, and normalized neural verification, TrustRAG secures RAG pipelines within a $55.84\text{ ms}$ CPU budget.
