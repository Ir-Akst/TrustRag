## 2. Reproducibility & Dependency Assessment

- **Offline Determinism:** Where experiments executed (`Phases 04, 05, 07, 08`), determinism is high: `set_random_seed(42)` ([repro.py](file:///c:/Users/Dell/Desktop/trustrag/src/trustrag/utils/repro.py)) fixes `random` and `numpy`; TF-IDF + rule verifiers are fully deterministic (`reproducibility_seed42_exact = true` in Phase 07); SHA-256 manifests and JSON artifact checksums (`platt_calibrator_v1.json`, `temperature_calibrator_v1.json`) match source outputs.
- **Reproducibility Broken in Working Tree:** Because uncommitted post-Phase 09 repository minimization deleted `tools/phase07_benchmark_audit.py`, `tools/phase08_comprehensive_benchmark.py`, `src/trustrag/evaluation/`, `src/trustrag/data/`, `data/benchmarks_backup/`, and `data/raw/`, **none of the Phase 04–08 benchmark scripts can be re-executed directly from the current working tree** without checking them out from `1eeb831` or rebuilding the scripts/splits. Only [benchmark_reference.json](file:///c:/Users/Dell/Desktop/trustrag/configs/benchmark_reference.json) (a static copy of `1eeb831:reports/phase08_comprehensive_benchmark.json`) and the 5 unit test modules remain runnable in WT.
- **Variance / Multi-Seed Reporting:** Phase 07 and Phase 08 executed strictly at `seed=42` single runs (`n=1` seed); Phase 04 checked seed invariance `[42, 123, 999]`, which held trivially because heuristic G1–G3 and `TfidfVectorizer` contain no stochastic training. Zero variance across neural initialization seeds has ever been measured because zero neural models were run or trained.
- **Unit Tests vs Real Experiments:** Working-tree unit tests (`tests/*.py`, `272` tests) and `1eeb831` unit tests (`377` passed, `2` deselected integration) use small deterministic strings, mock `loader_override` SRMs, and `2–10`-row working-tree files — they verify software contracts, **not** benchmark generalization.
