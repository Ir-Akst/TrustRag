## 1. Classification of Requirements: Core vs Supporting vs Optional

1. **Core TrustRAG Requirements (Paper B — `TrustRAG_RAG_Security_Paper.pdf`):**
   - End-to-end G1 (canonicalization + LLM dual-probe paraphrasing `q'`) -> Retrieval + G2 6-signal MSD (`ppl_z`, `norm_z`, `qmatch`, `instr`, `consensus_dev`, `prov`) -> Capped removal (`floor(K/2)` + down-weighting) -> G3 atomic claim verification, query consistency, and re-answering from high-trust `E_hat` -> Abstain/Release.
   - Core datasets/scenarios: **RSB benchmark** (all 13 attacks: `BPRAG`, `WPRAG`, `BPI`, `WPI`, `AGGD`, `CRAG-AS`, `CRAG-AK`, `JamInject`, `JamOracle`, `JamOpt`, `AgentPoison`, `BadRAG`, `Phantom`), **`EX-M` / `EX-L`** corpus composition stress tests, **`HaluEval-QA`** (`10,000` sample MSD feature ablation), and clean QA retrieval/generation utility (**`BoolQ`**, **`NQ`**, **`HotpotQA`**, **`MS-MARCO`**).
2. **Supporting Research References (Paper A — `HalluGuard`):**
   - Closed-book ~4B Qwen Small Reasoning Model (SRM) trained via **`FineWeb` -> `Dclean` -> `HalluClaim` / `HalluClaim-pref`** using **ORPO + LoRA**, supporting `think`/`non_think` inference and grounded/intrinsic/extrinsic span-cited classification.
   - Reference evaluation datasets: **`RAGTruth`** (`18,000` total, `84.0%` target balanced accuracy) and **`LLM-AggreFact`** (`75.7%` target balanced accuracy across sub-benchmarks **`AGGREFACT`**, **`TofuEval`**, **`WiCE`**, **`REVEAL`**, **`ClaimVerify`**, **`FactCheck-GPT`**, **`ExpertQA`**, **`LFQA`**).
3. **Optional External Benchmarks & Extensions (Paper C — `2508.02835v2.pdf` FilterRAG / ML-FilterRAG + `SQuAD`):**
   - Pre-generation passage filtering via **`Freq-Density`** computed from intermediate SLM answers `a_j = SLM(q_i, d_j)` and lightweight supervised **`ML-FilterRAG`** (`Freq-Density + perplexity + rank`) benchmarked on **PoisonedRAG** injections over **`NQ`**, **`HotpotQA`**, and **`MS-MARCO`**.
