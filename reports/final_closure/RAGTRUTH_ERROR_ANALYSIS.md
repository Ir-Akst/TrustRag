# RAGTruth Summary (N=50) — 12/25 Leakage Error Analysis

## 1. Overview
In Phase 44 (`seed=42`), `EvidenceGroundedVerifier` accepted **12 of 25** (`48.0%`, Wilson 95% CI `[30.03%, 66.50%]`) hallucinated summaries in `RAGTruth Summary` (`data/processed/ragtruth/test.jsonl`). Every leaked case was reproduced and instrumented without modifying production code or thresholds.

## 3. Root-Cause Taxonomy Summary
1. **NLI False Acceptance (`ent >= 0.50`) on Subtle/Extrinsic Summary Distortions (11/12 cases):** Frozen `deberta-v3-small` NLI assigns `entailment >= 0.50` when a summary claim shares high topical/lexical context with a source span but alters entity roles (`ragtruth_4472`), negates legal outcomes (`ragtruth_3147`), turns future/hypothetical events into completed facts (`ragtruth_2667`), or inserts plausible extrinsic commentary (`ragtruth_4574`, `ragtruth_4796`, `ragtruth_4030`, `ragtruth_2654`, `ragtruth_1965`).
2. **Full-Document Entity & Numerical Fallback Suppression (6/12 cases):** `_detect_semantic_entity_contradiction` and `_check_numerical_consistency` flagged span-level discrepancies in `ragtruth_1184`, `ragtruth_3639`, `ragtruth_613`, `ragtruth_4030`, `ragtruth_585`, and `ragtruth_2667`, but the cross-sentence full-document fallback cleared them because the entity/number appeared elsewhere in the long article.
3. **Answer-Level Release Ratio (`min_support_ratio_to_release = 0.75`) (3/12 cases):** `ragtruth_4472` (`4/5 = 80%`), `ragtruth_1184` (`6/7 = 85.7%`), `ragtruth_4030` (`5/6 = 83.3%`), and `ragtruth_585` (`6/8 = 75.0%`) each had 1–2 `UNSUPPORTED` claims yet passed the `0.75` release gate.
4. **Candidate Span Pre-Filtering (`top-16`):** Did **not** cause false acceptances (it only excluded numeric spans in `ragtruth_4472` and `ragtruth_585`, making those specific claims `UNSUPPORTED`).
5. **Honorific/Abbreviation Sentence Splitting (`Dr.`, `vs.`):** Caused minor claim fragmentation in `ragtruth_1184`, `ragtruth_585`, and `ragtruth_1965`.

## 4. Decision on Production Code
Production code is **left unchanged**. Adjusting `entailment_threshold`, `min_support_ratio_to_release`, or removing full-document cross-sentence fallbacks to target `RAGTruth Summary` would overfit to this 25-record split and regress `HaluEval` (`78.0%` recall) and cross-sentence synthesis. Instead, the `48.0%` RAGTruth Summary leakage is prominently disclosed as a scoped limitation.
